# Olist E-Commerce BI Project

## Overview
Complete Business Intelligence analysis of Brazilian E-Commerce dataset with 99,441 orders and R$ 16M revenue.

## Key Metrics
- **Total Orders:** 99,441
- **Total Revenue:** R$ 16,008,872
- **Avg Review Score:** 4.09/5
- **Avg Delivery Days:** 12.50

## Dashboards
- Business Overview
- Customer & Location
- Product Performance
- Delivery & Reviews

## Tools Used
- SQL (SQLiteStudio)
- Power BI Desktop
- ODBC Driver

## Data Source
Brazilian E-Commerce Public Dataset by Olist (Kaggle)
